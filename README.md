# Gor4akovNET

**Обход DPI на Keenetic/Netcraze — с телефона. Без ПК, без Termux, без root.**

[📥 Скачать APK](https://github.com/Garickbox/Gor4akovNET/releases/latest) · [🐛 Баги](https://github.com/Garickbox/Gor4akovNET/issues)

</div>

## Зачем

Провайдеры режут YouTube, Discord, Instagram через DPI. Gor4akovNET поднимает **zapret2 (z2k + nfqws2)** на роутере и направляет трафик через него. Всё с телефона, никакого ПК и root.

- **Всё офлайн** — `z2k-enhanced`, `.ipk` пакеты и AdGuardHome вшиты в APK
- **Мастер из 5 шагов** — каждый с проверкой, без скрытых действий
- **Автобэкап перед изменениями** — снимок всего `/opt` + конфига NDMS
- **Откат в один клик** — с pre-snapshot и без потери части конфига
- **Изолированная сеть** — отдельная Wi-Fi сеть для обхода (по желанию)
- **Обход во всех сетях** — Home, Guest и изолированная работают одновременно

## Что делает установка

За один прогон (60–90 сек):

1. **Preflight** — проверяет `/opt` (Entware смонтирован), `opkg`, наличие `nfqws2`
2. **Бэкап** — `tar` всего `/opt` + `running-config` NDMS → сохраняется на телефоне
3. **Распаковка офлайн-пакетов** из APK: `.ipk`, `z2k-enhanced`, `nfqws2`
4. **Сборка zapret2** — GNU tar, Lua-инициализация, установка `/opt/zapret2`
5. **Сеть** (если включена) — новый `BridgeN`, DHCP, `ip nat`, Wi-Fi `Gor4akovNET`
6. **AdGuard Home / WARP** (по желанию)
7. **Проверка** — `nfqws2` работает, интернет есть, обход в Home работает

## Совместимость

**Прошивка:** KeeneticOS 3.7+ / Netcraze OS 5.x · компоненты `OPKG` + `Netfilter` + `SSH` · USB `ext4` или внутренняя память

## Быстрый старт

1. **Установи APK** → подключись к Wi-Fi роутера
2. **Мастер → Шаг 1:** IP роутера + пароль от веб-меню (admin)
3. **Шаг 2:** USB — флешка → «Отформатировать в ext4» (или используй внутреннюю память)
4. **Шаг 3:** компоненты — `OPKG`, `Netfilter`, `WebDAV`, `SSH` (мастер проверит)
5. **Шаг 4:** SSH-пароль — по умолчанию `keenetic`. Есть «Автоподбор» (пробует пустой, `keenetic`, `admin`)
6. **Шаг 5:** «Установить в 1 клик» → 60–90 сек → «Обход работает»

## Изолированная сеть Gor4akovNET

Мастер может создать **отдельную Wi-Fi сеть** для устройств, которым нужен обход, но не нужен доступ к домашним.

- Свой SSID `Gor4akovNET` + пароль (генерируется в мастере)
- Свой `BridgeN` с подсетью `192.168.77.0/24` (если занята — берётся следующая)
- **`ip nat` включён автоматически** — интернет в сети есть
- **Обход работает везде** — он реализован через `NFQUEUE` на уровне WAN, а не через `ip policy` на bridge

> ⚠️ **Раньше было по-другому.** Старые версии вешали `ip policy Gor4akovNET` на bridge. У этой политики `no permit global ISP` → интернет в новой сети блокировался, а хук `090-gor4akov-policy.sh` исключал Home из обхода. Оба бага исправлены в текущей версии.

## Бэкап

**Что сохраняется (`filesDir/backups/`):**

- **Весь `/opt`** — пакеты, конфиги, AdGuard, dropbear-ключи, cron, `/opt/zapret2`, `/opt/bin`, `/opt/sbin`, `/opt/lib`
- **`running-config.txt`** — весь конфиг NDMS (Wi-Fi, политики, DHCP, статические IP, MAC)
- **`router-info.txt`** — `uname -a`, `df -h`, `/proc/mounts`, `opkg list-installed`
- **`manifest.json`** — версия архива

**Что НЕ сохраняется** (восстанавливается из APK или генерируется заново):

- Файлы на флешке вне `/opt` (музыка, документы) — их нужно бэкапить отдельно
- Логи (`/opt/var/log`, `*.log`)
- Мусор установки (`gor4akov-offline`, `z2k-work`, `z2k-rollback`, `tmp`)

**Размер:** `/opt` ~230 МБ → сжатый `.tar.gz` ~86 МБ. Передача по SSH ~2 сек при 60 МБ/с.

**Механика:** `tar` пишет архив на флешку (`/opt/.gbox_backup_stage.*.tar.gz`), проверяется `tar -tzf`, потом стримом (`PullFileSSH`) уходит на телефон. Обрыв флешки / Wi-Fi → **бэкап не сохранится** (порог 4 КБ + `exit $tar_rc`).

## Восстановление

Два режима из UI:

### «Только обход» (`bypass`)

Заменяет `/opt/zapret2` + `/opt/etc/ndm/netfilter.d`. Остальное не трогает.

### «Полная замена /opt» (`opt_full`)

1. **Pre-snapshot** текущего `/opt` → `/opt/.gbox_prerestore.*.tar.gz` (сохраняется, если что-то пойдёт не так)
2. **Стоп служб** — `S99zapret2`, `S99AdGuardHome`, `S10cron`, `nfqws2`, `AdGuardHome`
3. **Удаление** папок, которые есть в бэкапе (`etc`, `zapret2`, `bin`, `sbin`, `lib`, `usr`, `var`, …)
4. **Распаковка** из архива
5. **Старт служб** — по порядку, с проверкой `nfqws2` в конце
6. **При ошибке** — автоматический откат из pre-snapshot

### «Полный системный откат» (`system_full`)

То же + восстановление носителей (`/tmp/mnt`, `/media`) + полный `running-config` NDMS (Wi-Fi, политики, DHCP, статические IP, MAC — **как в бэкапе**).

> ⚠️ После `system_full` IP роутера может смениться на тот, что был в бэкапе. Переподключись к сети роутера.

## Решение проблем

| Симптом | Причина | Что делать |
|---|---|---|
| `step_check_root: not found` | z2k-модули не подгрузились | Обновись на APK ≥ `9e667d0` — фикс `WORK_DIR`/`LIB_DIR` |
| `ssh: unable to authenticate` | Пароль с хвостовым пробелом / не сохранён | Монитор → Логи & SSH → 🔑 Креды: `root` / `222` / пароль без пробелов |
| Бэкап «пустой» (5 КБ) | Флешка отвалилась / `tar` упал | Роутер → переустанови флешку, повтори бэкап. `tar -tzf` проверит архив |
| «Ошибка бэкапа: pull exit: Process» | GNU tar не найден | Проверь `/opt/bin/tar` (`ls -la`); переустанови Entware |
| Нет интернета в `Gor4akovNET` | `ip nat` не включён | `ndmc -c "ip nat Bridge2"` + `system configuration save` |
| YouTube не работает в Home | Хук `090-gor4akov-policy.sh` (в старых APK) | Удали файл из `/opt/etc/ndm/netfilter.d/`, `S99zapret2 restart` |
| `nfqws2 НЕ стартовал` | Конфиг `/opt/zapret2/config` битый | Монитор → Z2K → «Подбор стратегии» |
| Wi-Fi радиомодули красные | SSH auth падает | Проверь креды SSH, вкладка «Клиенты» не откроется без SSH |

## Безопасность

- **MAC-адрес** — не меняется при восстановлении, он привязан к железу
- **Пароли** — в бэкапе, но бэкап внутри `filesDir` (не попадает в `/sdcard`, не утекает через файловый менеджер)
- **SSH** — Dropbear из Entware, отдельный пароль от веб-меню
- **Обход** — работает на уровне ядра (`iptables NFQUEUE`), не через прокси-сервисы

## Что НЕ делает

- **Не требует root** — всё через SSH/WebDAV/RCI
- **Не меняет прошивку** — только добавляет `/opt` (Entware)
- **Не работает на 128 МБ** — RAM не хватит на AdGuard + nfqws2
- **Не бэкапит файлы пользователя на флешке** — только систему
